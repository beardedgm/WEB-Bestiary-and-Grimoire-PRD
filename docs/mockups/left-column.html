Bestiary & Grimoire: left column

Four ways to split monsters, spells, party, and encounters. Fake data only. Pick a direction before we wire this into the app.

Open this file from the repo: http://127.0.0.1:8000/docs/mockups/left-column.html. Toggle Tracker below to see the add / load controls that would appear in combat prep. Tabs inside each mock switch the list.

Preview as

1. Four peer tabs

Monsters, Spells, Party, and Encounters sit as equal tabs. Catalog filters (system + scale) only appear on Monsters or Spells. Party and Encounters get a list plus New. Closest to “everything lives in the left column.”

2. Two-row nav

Row 1 is the catalog (Monsters | Spells). Row 2 is quieter prep (Party | Encounters). Catalog stays primary; party and encounters are always one click away without four equal tabs crowding 340px.

3. Catalog vs table

A top segment chooses Catalog or Table. Catalog inner tabs: Monsters / Spells. Table inner tabs: Party / Encounters. Library can default to Catalog; Tracker can default to Table, without changing the header mode buttons yet.

4. Stacked sections

No tabs. Four collapsible blocks. Filters live inside the open catalog section. Everything can be visible at once. Usually cramped at this width; useful as a contrast.
