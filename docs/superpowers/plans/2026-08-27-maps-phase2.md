# Maps (Phase 2) — full local HexPlora parity — 2026-08-27

Supersedes `2026-08-27-maps-phase2-outline.md`.

## Goal

Campaign **Maps** mode: many maps per active campaign; each = background image + hex overlay + fog + tokens + APP-class annotations; offline; **PixiJS**; IndexedDB `bg-maps`; HexPlora-compatible import/export.

## Architecture

- Meta: `bg.campaign.v1` → `campaign.maps[]` `{ id, name, updatedAt }`
- Heavy: IndexedDB DB `bg-maps` / store `maps` → `{ id, name, blob, state, updated }`
- UI: `#m-maps` + `#maps` full-bleed (Lore pattern); `window.MAPS` in `maps/maps-app.js`
- Vendor: `maps/maps-pixi.bundle.js` (Pixi 8.17.1 IIFE); rebuild via `maps/npm run build:pixi`
- Portable `bg-user-save/1`: maps **meta only**; map pixels via `.hexplora` export

## Tools (done checklist)

Pan, Reveal, Hide, Token, Measure, Text, Brush, Shapes (rect/ellipse/arrow/line), Undo/Redo, Reset fog / Clear tokens / Clear annotations, Screenshot PNG, Import/Export, grid settings.

## Non-goals

Square grid UI, Library-linked tokens, Quest/Audio, share/QR, React HexPlora shell, map blobs in portable JSON.
